# Responsive Web & PWA UX — CRITICAL

* **Safe Area Support:** Respect mobile safe-area insets for root layouts, top bars, bottom navigation, sheets, and floating actions.
* **Back Navigation:** Browser Back and mobile swipe-back must dismiss the currently open drawer, modal, sheet, action menu, or numpad before leaving the current page.
* **App Lock:** When Passcode or Biometrics is enabled, lock the application when it returns to the foreground after being hidden.
* **PWA Support:** Maintain PWA installability and an offline app shell for fast startup, while keeping all application data operations online-only.
* **Touch Friendly:** Ensure interactive controls are comfortable for touch and remain usable across mobile viewport sizes.
* **Input Behavior:** Prevent unwanted mobile zoom and viewport issues during form interaction.
* **Scroll Behavior:** Prevent accidental page-level pull-to-refresh where it interferes with application scrolling.
* **Responsive Adaptation:** Treat mobile and desktop as first-class layouts and adapt navigation, overlays, tables, forms, and dense data views appropriately.

**Core Principle:** The application should feel **native, predictable, touch-friendly, and responsive** across mobile and desktop.
